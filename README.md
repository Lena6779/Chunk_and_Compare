This project compares two chunking strategies for semantic search. A document is split into fixed-size chunks (300 characters with 50 overlap) and into paragraph-based chunks. Both sets are embedded with the all-MiniLM-L6-v2 model, and the same three queries are run against each. The top two results and their similarity scores are printed side by side. Fixed-size chunks scored higher overall, but paragraph chunks returned the correct topic first on every query, which shows that similarity scores alone can be misleading when chunk sizes differ.
